| 2026-11-17 | Model swap + honesty layers | User said the machine "does not work really well" and asked for accuracy on all sorts of things plus general chatting, noting the tiny model fails for the tiniest reasons. Two decisions were put to the user: model (chose Qwen2.5-0.5B-Instruct-q4f16_1-MLC, ~265 MB — Apache 2.0, prebuilt in web-llm, ~945 MB VRAM; SmolLM2-360M ~195 MB and Llama-3.2-1B ~700 MB were the other options) and web access (chose opt-in Wikipedia toggle, default off). Built four honesty layers around the 0.5B model: (1) deterministic small talk — the model never sees greetings/farewells/meta questions, they are answered by `lib/machine/smalltalk.ts`; (2) expanded curated KB 45 → 69 chunks with noise blocklist (right/real/ready/color/sky/answer/life/…) plus an English-theme escape hatch (test/verify/contact/hire/…) so hyper-generic questions neither pass nor leak; (3) `extractiveAnswer()` — the sentence in the note that best matches the question (+0.6 for digits) replaces degenerate/echoing prose; it powers every fallback (empty answer, figure-free answer, verbatim echo, weak paraphrase); (4) opt-in Web mode — off by default; Wikipedia opensearch (stopword-stripped core, 2-token overlap or trailing-entity rule, extract must carry the question's subject vocabulary, UK→US spelling map) supplies a note the model paraphrases with a source chip to the article; portfolio notes always answer first. Supersedes the 2026-11-08 135M pivot. |
| 2026-11-17 | The fallback is a real answering system, not a canned demo | User: “keep the fallback as an answering system that can answer no matter what… users on mobile probably wont download the model.” The 12-answer keyword demo could not answer arbitrary questions, so it was replaced with `lib/machine/fallback.ts`, a modelless QA composer over the 69-chunk curated KB: deterministic small talk → retrieval → evidence questions emit the note's recorded `facts` verbatim (same voice as the model path) → everything else composes the question-best sentence in the top note plus a contiguous neighbour, capped at ~470 chars and whole sentences. Web mode (opt-in, off by default) cascades Wikipedia in only when the notes cannot answer; refusal is exact when there is no source. Follow-ups chain through the same project ref as the model path. User-facing copy renamed from “Demo mode” to “Instant answers — composed from the notes”; internal `mode: "demo"` stays. Sources chips always point at the note or article used, so the fallback is honest by construction. |
