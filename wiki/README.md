# Parth Varekar Portfolio — Knowledge Wiki

This wiki is the durable memory for the project. If a session stops unexpectedly, read this folder first, then `wiki/05-progress.md`, then continue from the next unchecked task.

## Read in this order

1. **`00-context.md`** — who the site is for, the brief, and the locked decisions.
2. **`01-research.md`** — verified identity, repositories, model research, design reference.
3. **`02-design-system.md`** — palette, type, layout, components, motion.
4. **`03-architecture.md`** — stack, routes, machine architecture, retrieval, file map.
5. **`04-content.md`** — project facts and copy rules.
6. **`05-progress.md`** — milestone checklist, current state, next action, changelog.
7. **`06-decisions.md`** — decision log with dates.
8. **`07-qa.md`** — test plan, results, known issues.

## Update protocol

After every milestone or meaningful change:

1. Tick the relevant item in `05-progress.md`.
2. Add a dated entry to the **Changelog** at the bottom of `05-progress.md`.
3. Record any new architectural or design decision in `06-decisions.md`.
4. Record test results and known issues in `07-qa.md`.
5. Keep `04-content.md` in sync with any copy or project changes.
