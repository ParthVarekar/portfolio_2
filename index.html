Case Study // WhisperFlow

Offline
Speech Pipeline.

Problem Space

Cloud dictation tools (Wispr Flow, Superwhisper) send your audio to remote servers. For sensitive workflows — medical, legal, development — that's a privacy non-starter.

Architectural Logic

A fully offline pipeline: whisper.cpp transcribes audio via a compiled C++ binary, llama.cpp reasons over the transcript via a local HTTP server. The Python orchestrator has zero runtime pip dependencies — stdlib only.

  • 01_ Wispr Flow feature parity: push-to-talk daemon, system tray, floating overlay
  • 02_ Win32 SendInput text injection — inject transcribed text into any focused app
  • 03_ Context-aware app detection + voice snippets
  • 04_ 77/77 unit tests passing across 8 test modules

Case Study // Agent Safety Net

Browser AI
Safety Layer.

Problem Space

Browser-based AI agents (ChatGPT, Claude) can read your DOM and make outbound requests — including your PII. There's no runtime safety layer inspecting what leaves your browser.

Architectural Logic

A Chrome MV3 extension that injects into the page's MAIN world to monkey-patch fetch and XMLHttpRequest. Captured payloads route to the Service Worker, where local regex PII detection + prompt-injection pattern matching run deterministically — avg 0.011ms, ~90,000 req/sec — with an LRU cache for sub-millisecond repeated lookups.

  • 01_ MAIN world script injection bypasses declarativeNetRequest body-inspection limits
  • 02_ 4-tier intervention UI: Allow (silent) / Warn (toast) / Confirm (modal) / Block (interstitial)
  • 03_ Intent-drift detection: sensitive DOM read → unrecognized POST within 5s
  • 04_ Gemini Flash 2.5 used only for async post-block explanations
